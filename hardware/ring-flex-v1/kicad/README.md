# KiCad project — ring-flex-v1

`ring-flex-v1.kicad_sch` is generated by `gen_sch.py` from the design in
[../NETLIST.md](../NETLIST.md). Regenerate with:

```bash
python3 gen_sch.py
```

Every pin gets a short stub wire and a net label; nothing is routed by hand.
That makes the file electrically complete and machine-checkable. Placement is
deliberately plain — tidy it in the schematic editor, that is a human job.

## Verification

```bash
KICAD=/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli
$KICAD sch erc --output erc.rpt --severity-all ring-flex-v1.kicad_sch
$KICAD sch export netlist --format kicadsexpr --output netlist.net ring-flex-v1.kicad_sch
```

**ERC: 0 electrical violations.** The 30 remaining entries are all
`lib_symbol_issues` — `kicad-cli` runs without the global symbol library
table, so it reports that it cannot find `Device`, `Connector` and friends.
They do not appear in the GUI.

The export also prints an annotation warning. The netlist itself carries
correct references throughout; open the schematic and let the editor
re-annotate if it bothers you.

## Before layout

**The MDBT50Q-1MV2 pin numbers are placeholders** (`P1`-`P7`). They must be
set from the Raytac datasheet. Inventing them would have produced a
plausible-looking schematic that silently builds a dead board.

No footprints are assigned yet.

## Things this cost, recorded so the next person does not repeat them

Four format details about KiCad 10 schematics, each found by bisection:

1. UUIDs are quoted: `(uuid "...")`, not `(uuid ...)`.
2. The current file version is `20250610`. A `20250114` file uses a different
   convention for embedded symbol names.
3. In `lib_symbols`, only the **outer** symbol takes the library prefix
   (`Device:R`). Its unit sub-symbols keep plain names (`R_0_1`, `R_1_1`).
   Prefixing those makes the file fail to load, with no error message.
4. `.kicad_sym` libraries carry `in_pos_files`, `do_not_autoplace` and
   `show_name`, which the schematic parser does not accept. Strip them.

Also: everything must sit on the 1.27 mm grid, or wire endpoints are not
treated as touching pins.
